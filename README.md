# Diary Note Web App

A simple web application for writing and saving diary notes.

## Features
- Write and save notes
- View saved notes with timestamps
- Local storage for persistence

## How to Use
1. Open `index.html` in a web browser.
2. Write your note in the textarea.
3. Click "Save Note" to save it.
4. View your saved notes below the form.

## Files
- `index.html`: Main HTML file
- `styles.css`: Styling for the app
- `script.js`: Functionality for saving and displaying notes

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
